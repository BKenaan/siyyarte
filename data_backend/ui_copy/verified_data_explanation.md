# How Siyyarte Verifies Data (user-facing)
- Siyyarte shows maintenance and fluid data **only from official manufacturer sources** (owner's manuals, official service/maintenance guides).
- Every value is **market-scoped** (GCC vs US-import) and **cited** — tap any value to see the source document and page.
- Some vehicles are **partially supported**; we show what's verified and mark the rest as pending — we never guess.
- Siyyarte is a helpful reference, **not a replacement** for your vehicle's official owner's manual or a qualified mechanic.
